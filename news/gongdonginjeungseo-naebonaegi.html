공동인증서 내보내기, 기업은행을 안 써도 될까요? — 화면 그대로 따라하는 순서

기업은행을 쓰지 않아도 괜찮습니다. 공동인증서를 바탕화면으로 내보내 담당자에게 전달하는 방법을 화면과 강조 표시 그대로 정리했습니다. 인증서 파일과 비밀번호를 안전하게 넘기는 방법도 함께 확인하세요.

원격 경리 전문 서비스

기업은행을 쓰지 않으셔도 됩니다

국민·신한·우리·하나 등 다른 은행을 이용 중이셔도 괜찮습니다.
어느 은행을 쓰시든, 기업은행 홈페이지에서 그대로 진행하시면 됩니다.

아래 화면을 그대로 보시고, 분홍색 네모가 쳐진 곳만 순서대로 눌러 주세요. 실제 화면과 조금 달라도 순서는 같습니다.

1기업뱅킹 접속 → [인증센터] → [공동인증서] 탭

기업은행 i-ONE Bank 기업뱅킹에 접속해 오른쪽 위 인증센터를 누르고, 공동인증서(구 공인인증서) 탭을 선택합니다. 기업은행을 쓰지 않으셔도 이 화면에서 그대로 하시면 됩니다.

주소: https://kiup.ibk.co.kr/uib/jsp/index.jsp

2[공동인증서 관리] → [자세히 보기]

인증센터에서 공동인증서 관리 항목의 자세히 보기를 누릅니다.

3인증서 선택 → [내보내기] → 암호 입력 → 바탕화면 저장

[인증서 관리] 창에서 보내실 인증서를 선택하고 내보내기를 누른 뒤, 인증서 암호를 입력하고 저장 위치를 바탕화면으로 골라 [저장]합니다.

※ 화면 속 회사명은 실제 회사·개인과 무관한 가상 예시입니다.

4바탕화면에 만들어진 파일을 담당자에게 전달

바탕화면에 생성된 인증서 파일을 경청 담당자에게 보내주시면 됩니다.

꼭 지켜주세요

  • 인증서 파일과 비밀번호는 안내받은 담당자에게만 보내주세요. 다른 곳에는 전달하지 마세요.
  • 파일과 비밀번호를 같은 메시지에 함께 보내지 마시고, 비밀번호는 담당자와 통화로 알려주세요. 안내받지 않은 번호·링크로는 보내지 마세요(사칭 주의).
  • 보내신 뒤 바탕화면에 남아 있는 인증서 파일은 삭제해 주세요.
  • 보내주신 파일은 위탁받은 경리·증빙 업무 범위 안에서만 사용하고, 업무가 끝나면 안전하게 폐기합니다.

순서가 헷갈리거나 화면이 다르게 보이면 언제든 담당자에게 연락 주세요. 기업은행을 쓰지 않으셔도 그대로 진행하실 수 있고, 경리 아웃소싱(경리대행)으로 맡기실 때도 인증서 준비부터 함께 도와드립니다.

경리 아웃소싱, 무료 상담으로 확인하세요
